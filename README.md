# PanelPatch · 面板试图台

从正拍显示面板的灰阶试图照片圈定测量框。在同一张原照点取几处已知正常的位置做为参考点，再选一根竖截线，读取真实 RGB 和亮度，或查看该截线各像素相对当地参考的偏差。每个像素的当地参考由能围住它的三个参考点按原坐标三角加权得到：任一 RGB 通道为 0 或 255 的参考点不采用，三点共线也不采用；若同一像素有多种可围住的三角，优先参考点靠近且三角不过分狭长的组合。没有被三点围住的位置留作无参考，不向外推，也不计入限内。偏差采用照片 8 位 RGB 的亮度，适合在相同照片内复查，并保留原图坐标。

“打开练习面板”使用注明为合成的照片。可以上传单帧 PNG、JPEG、TIFF、BMP 或 WebP。保存后可检查原列、比较框内所有列均亮与亮暗越限计数、下载 CSV、校样 PNG 和带原照的观察 ZIP，或将整张原照送入照片准备。

`docker compose up --build` 后访问 `http://127.0.0.1:19921/`。独立命名卷保存观察卡和准备工程。
