# PanelPatch · 面板试图台

从正拍显示面板的灰阶试图照片圈定测量框。在原照选一个参考像素和一根竖截线，读取真实 RGB 和亮度，或查看该截线各像素相对参考的偏差。偏差采用照片 8 位 RGB 的亮度，适合在相同照片内复查，并保留原图坐标。

“打开练习面板”使用注明为合成的照片。可以上传单帧 PNG、JPEG、TIFF、BMP 或 WebP。保存后可检查原列、比较框内所有列均亮与亮暗越限计数、下载 CSV、校样 PNG 和带原照的观察 ZIP，或将整张原照送入照片准备。

两档灰阶可用“两档灰阶配对”把当前卡与另一张已存卡沿各自已保存的竖截线比较：两张卡各用自己的参考点和偏差限值；任一通道为 0 或 255 的越限点不参与，只有同为偏亮或同为偏暗、原 Y 差不超过所填像素数的点按从上到下的顺序一一配对。优先配出更多点，其次选原 Y 更近、偏差更相近的组合。配对后点选一处匹配即可切到另一张原图，读取该卡实际配对像素的 X、Y、RGB 与亮度；没配上的点保留在原截线位置并标为未配。

`docker compose up --build` 后访问 `http://127.0.0.1:19921/`。独立命名卷保存观察卡和准备工程。
